<SectionHeader
    title="Overview"
    subtitle="Lipa Na Bonga enables customers to convert accumulated Bonga loyalty points into payments for goods and services. The integration involves two main steps: calculating the point conversion value and initiating the redemption request."
    size="small"
/>

<Alert type="info" title="Implementation Options">
    - Use the MpesaClient facade for simple and safe integration: it manages authentication, header injection and returns typed Pydantic models.
    - Use the Direct API (BongaService + TokenManager + HttpClient) if you need full control over request/response handling, middleware, or custom error behaviors.
    - Both are available as sync and async variants (`MpesaClient`/`AsyncMpesaClient`, `BongaService`/`AsyncBongaService`) — reach for async when performing point calculations or redemptions concurrently across multiple channels.
</Alert>

<Tabs defaultValue={0}>
    <Tabs.TabPane label="MpesaClient (Recommended)" icon="🚀">
        <Alert type="info" title="Why use MpesaClient">
            The facade handles token retrieval and attaches Authorization headers so you can call high-level operations like calculating and redeeming Bonga points with minimal boilerplate.
        </Alert>

        <SectionHeader title="Quick Setup (Sync)" size="small" />

        <CodeBlock language="python" title="Python">
{`
# Example: calculate points and redeem them using the high-level client
from mpesakit import MpesaClient

client = MpesaClient(consumer_key="...", consumer_secret="...", environment="sandbox")

# Step 1: Calculate points value
calc_resp = client.bonga.calculate_points(points=50)

if calc_resp.is_successful:
    print(f"50 points = KES {calc_resp.body.amount}")
    
    # Step 2: Trigger redemption
    redeem_resp = client.bonga.redeem_points(
        msisdn="254720776155",
        amount=calc_resp.body.amount,
        bonga_points=50,
        conversion_rate=float(calc_resp.body.rate),
        short_code="174379",
        account_number="WebCheckout"
    )

    if redeem_resp.is_successful:
        print("Redemption initiated successfully!")
    else:
        print("Redemption failed:", redeem_resp.header.customerMessage)
else:
    print("Calculation failed:", calc_resp.header.responseMessage)
`}
        </CodeBlock>

        <Alert type="info" title="Notes">
            - The facade returns typed Pydantic models (e.g., CalculatePointsResponse, RedeemPointsResponse) for ergonomic access to headers, bodies, and helpers like is_successful.
            - Authentication tokens are handled transparently by the client.
        </Alert>

        <SectionHeader title="Quick Setup (Async)" size="small" />

        <CodeBlock language="python" title="Python">
{`
import asyncio
from mpesakit import AsyncMpesaClient

async def main():
    async with AsyncMpesaClient(
        consumer_key="...", consumer_secret="...", environment="sandbox"
    ) as client:
        calc_resp = await client.bonga.calculate_points(points=100)

        if calc_resp.is_successful:
            redeem_resp = await client.bonga.redeem_points(
                msisdn="254720776155",
                amount=calc_resp.body.amount,
                bonga_points=100,
                conversion_rate=float(calc_resp.body.rate),
                short_code="174379",
                account_number="WebCheckout"
            )

            if redeem_resp.is_successful:
                print("Async redemption successful!")
            else:
                print("Redemption failed:", redeem_resp.header.customerMessage)

asyncio.run(main())
`}
        </CodeBlock>

        <Alert type="warning" title="Manual lifecycle (without the context manager)">
            In a long-lived service (e.g. `AsyncMpesaClient` wired up as a FastAPI dependency), construct it once at startup and call `await client.aclose()` on shutdown instead of opening a new `async with` block per request.
        </Alert>
    </Tabs.TabPane>

        <SectionHeader title="Direct Implementation (Sync)" size="small" />

        <CodeBlock language="python" title="Python">
{`
# Example: construct and send requests using BongaService directly
from mpesakit.services.bonga_service import BongaService
from mpesakit.bonga import CalculatePointsRequest, RedeemPointsRequest
from mpesakit.auth import TokenManager
from mpesakit.http_client import MpesaHttpClient

http_client = MpesaHttpClient(env="sandbox")
token_manager = TokenManager(consumer_key="...", consumer_secret="...", http_client=http_client)
bonga_service = BongaService(http_client=http_client, token_manager=token_manager)

# Calculate points
calc_response = bonga_service.calculate_points(points=40)
print("Amount:", calc_response.body.amount)

# Redeem points
redeem_response = bonga_service.redeem_points(
    msisdn="254720776155",
    amount=calc_response.body.amount,
    bonga_points=40,
    conversion_rate=float(calc_response.body.rate),
    short_code="174379",
    account_number="test"
)
print(redeem_response.header.responseMessage)
`}
        </CodeBlock>

        <SectionHeader title="Direct Implementation (Async)" size="small" />

        <CodeBlock language="python" title="Python">
{`
import asyncio
from mpesakit.services.bonga_service import AsyncBongaService
from mpesakit.auth import AsyncTokenManager
from mpesakit.http_client import MpesaAsyncHttpClient

async def main():
    async with MpesaAsyncHttpClient(env="sandbox") as http_client:
        token_manager = AsyncTokenManager(
            consumer_key="...", consumer_secret="...", http_client=http_client
        )

        bonga_service = AsyncBongaService(http_client=http_client, token_manager=token_manager)

        calc_response = await bonga_service.calculate_points(points=40)
        print("Amount:", calc_response.body.amount)

        redeem_response = await bonga_service.redeem_points(
            msisdn="254720776155",
            amount=calc_response.body.amount,
            bonga_points=40,
            conversion_rate=float(calc_response.body.rate),
            short_code="174379",
            account_number="test"
        )
        print(redeem_response.header.responseMessage)

asyncio.run(main())
`}
        </CodeBlock>

        <Alert type="info" title="Direct API Details">
            - The Bonga service attaches the Authorization header using the provided TokenManager (sync or async, matching the client you chose).
            - Responses are fully typed into Pydantic models for safe consumption.
        </Alert>

<SectionHeader title="Testing & Expected Behaviors" size="small" />

- Calculate Points:
    - The service posts to `/v1/lipa/na/bonga/calculate-points` with the Authorization header set via TokenManager.
    - Returns a `CalculatePointsResponse` instance containing the converted amount, points, and rate.

- Redeem Points:
    - The service posts to `/v1/lipa/na/bonga/redeem-paybill` with redemption details.
    - Triggers an STK push prompt on the customer's phone for PIN verification.
    - Returns a `RedeemPointsResponse` instance with status headers.
